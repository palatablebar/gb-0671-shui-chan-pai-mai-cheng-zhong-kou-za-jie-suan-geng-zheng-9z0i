# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
归档封存保存逐版证据、隔离原因和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。

## 弃标处置

弃标回报 `abandonment_reports`：`report_id`（回报号）、`ticket`、`version`（弃标时成交版本，缺省为当前生效版）、`reported_at`、`buyer`、`reason`、`evidence`（凭据，任意非空结构）。重拍尝试 `resale_attempts`：`attempt_id`、`report_id`、`status`（filled/failed 等）、`switch_status`（ok/failed/rollback）、`buyer`、`amount`（申报成交额）、`net_kg`/`price`/`rate` 或 `billable_kg`（用于重算）、`effective_at`、`evidence`。

重拍成交额优先采信申报额，并与净重×(1−扣杂率)×单价的重算值比对；相差超过 0.01CNY 视为不可确认，不执行切换。成交差额=原成交−重拍成交；成交缺口=max(成交差额, 0)。应追差额取「弃标时已认成交额−重拍成交」与成交缺口的较小者，弃标后更正抬高的余量计为待追认更正；重拍高于原成交时溢余，应追为零。入账额取原成交与重拍的较大者，与无弃标时的原成交相等，确保不重复结算。未结清应追=应追差额−该票已付，反向为可退预付；重拍后待收现款=重拍成交+未结清应追。对账四账的已付与待付仍按原成交记录，处置页单独列示退款与重拍收款，两者不相互替代。
